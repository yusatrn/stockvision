# Phase 6 — Frontend Dashboard

Build the Next.js frontend in TypeScript.

Requirements:
- Responsive professional financial dashboard with dark/light themes.
- Navigation: Dashboard, Markets, Screener, Watchlist, Portfolio, Alerts, Settings.
- Dashboard cards: market summary, watchlist movers, latest analysis runs and data freshness.
- Instrument detail page with candlestick chart, volume and selectable indicators.
- Use TradingView Lightweight Charts; include attribution/license compliance as required by its current license.
- API access through a typed service layer; do not scatter fetch calls across components.
- Loading, empty, error and stale-data states.
- Accessible labels, keyboard navigation and semantic HTML.
- Show simulated-data badge when mock provider is active.
- Add frontend tests for key components and API client behavior.
- Do not hardcode sample values in production-facing components; use mock API environment only.

Update frontend README and run lint, typecheck and tests.
